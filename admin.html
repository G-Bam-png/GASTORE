Настройка облака

Нужно создать бесплатное хранилище на JSONBin.io — это займёт 2 минуты. Товары сразу появятся у всех клиентов на любом устройстве.

1 Зарегистрируйтесь на JSONBin.io

Перейдите на jsonbin.io → нажмите Sign Up → войдите через GitHub или email. Это бесплатно.

2 Получите API-ключ

После входа нажмите на иконку профиля вверху → API Keys → скопируйте Master Key (длинная строка начинается с $2b$)

3 Создайте хранилище (Bin)

Нажмите кнопку ниже — хранилище создастся автоматически с вашим API-ключом.
